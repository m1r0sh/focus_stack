# focus_stack

GUI-программа на Python для стекинга изображений с двумя вкладками:

- **Ландшафт (фокус-стекинг)** — объединяет серию кадров с разным фокусом в один
  резкий снимок. Кадры выравниваются (ECC-сдвиг), резкость каждой точки
  оценивается через лапласиан, смешивание — лапласиевой пирамидой со
  скользящими весами (без швов и «призраков»). Есть тональные пресеты:
  **Золотой час** (тёплый свет, S-контраст, насыщенность) и **Синий час**
  (холодный баланс, приподнятые тени).

- **Астрофото (Sequator)** — стекинг кадров ночного неба:
  - вычитание дарк-кадров (мастер-дарк по медиане);
  - выравнивание по звёздам (ORB + RANSAC, только область неба);
  - «заморозка» земли — земля берётся с эталонного кадра, линия горизонта
    задаётся ползунком;
  - режимы стекинга: среднее, медиана, максимум, отбраковка (сигма-клип);
  - пост-обработка: яркость, насыщенность, гашение цветного шума.

## Установка

```bash
pip install -r requirements.txt
```

Нужен Python 3.9+ с tkinter (на Linux: `sudo apt install python3-tk`).

## Запуск

```bash
python main.py
```

## Использование

1. Выберите вкладку: «Ландшафт» или «Астрофото».
2. Добавьте кадры (первый кадр — эталонный).
3. Настройте параметры и укажите файл результата.
4. Нажмите «Стекинг ▶».

Результат сохраняется как PNG/TIFF (16 бит) или JPEG (8 бит, качество 95)
в зависимости от расширения выходного файла.

## Тесты

```bash
python tests/test_stacking.py
```

Тесты генерируют синтетические серии (фокус-стекинг и сдвинутое звёздное небо)
и проверяют резкость результата и точность выравнивания.
